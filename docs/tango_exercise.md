# イメージで英単語エクササイズ（気合の英単語 初段）

自前の単語帳『気合の英単語 初段』（~/kiai-tango、入試頻出1000語＝100語×10稽古）の絵を見て、英単語を答える横長の動画。稽古ごとに1本（約13分）。

## 作り方
```
python3 tango_exercise.py 1              # 稽古1 → output/tango/keiko1.mp4 / .jpg（サムネ）/ _description.txt / .meta.json
python3 tango_exercise.py 1 --words 12   # 試作（最初の12語だけ）
python3 tango_exercise.py --channel-art  # チャンネルのアイコン・バナー → output/tango/channel_*.png
python3 tango_exercise.py 1 --upload     # 非公開でアップ（坂本さんの OK のあと）
```
- 画面：edu/src/tango/Tango.tsx（Remotion。解説ショートと同じ edu/ の中）
- 単語の発音：ElevenLabs の英語ネイティブの声（Alice、ondoku_audio.py と同じ）。セリフはキャラの声（edu/cast.json）
- 声・絵・表紙は edu/public/tango/ に貯めて使い回す（git には入れない）
- 購入リンク：data/tango_book.json。空のあいだ、説明文は「近日発売（発売したらここにリンクを載せます）」。動画の中の札は「くわしくは概要欄へ」なので、発売後も作り直さなくてよい

## 動画の流れ
1. 0〜6秒：単語帳の紹介（表紙・キャラ勢ぞろい・仙人のセリフ）
2. やり方（熱血・メガネ・仙人）
3. 1語ごと：絵と頭文字ヒント（3.5秒、最後の3秒は秒読み）→ 単語・品詞・意味 → 発音2回（あいだに、まねする間）
   10語ごとに見守るキャラが替わる（熱血→メガネ→ツンデレ→幼なじみ→イケメン→スパルタ→仙人…）
4. 締め（稽古N 完了・キャラ勢ぞろい・表紙）

## 守ること
- 著作権：単語・訳・例文・絵はすべて自前。アップロード前に book_guard.check を通す（tango_exercise.py の中で通している）
- 「改変・合成コンテンツ」の申告：不要と判断（2026-10-16）。YouTube の基準では、見た目が本物そっくり（実在の人・場所・出来事と見間違える）の合成だけが申告の対象で、アニメ・はっきり作り物と分かるものは対象外。この動画はドット絵のキャラなので当たらない。アップ時は containsSyntheticMedia=false を明示し、説明文に「イラストは AI（Google Gemini）で作成、声は AI 音声」と書く
- 公開・チャンネル設定の変更は坂本さんの OK のあと
